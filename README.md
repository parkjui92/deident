# deident — 한국 문서 민감정보 비식별화

한글(.hwpx)·워드·엑셀·발표자료에 든 이름·소속·주민등록번호·과제번호를
**서식은 그대로 둔 채 가명으로** 바꾸고, 바꾼 파일을 다시 뒤져 **통과한 것만** 내놓는 로컬 도구.
연구계획서·제안서·명단을 AI에 넣기 전, 또는 밖으로 내보내기 전에 쓴다.

```
연구책임자 | 홍길동 | 한국화학연구원 | 800101-1234567 | 010-1234-5678
        ↓
연구책임자 | [연구자A] | [기관A] | [주민등록번호1] | [휴대전화1]
```

같은 사람은 문서 어디서나 같은 가명을 받는다. 직함은 남는다(`홍길동 교수` → `[연구자A] 교수`).
외부 API를 쓰지 않으므로 원문이 컴퓨터를 떠나지 않는다.

> **English** — Local de-identification for Korean office documents (HWPX, DOCX, XLSX, PPTX;
> PDF is redaction-only). It replaces names, affiliations, resident registration numbers and
> project identifiers with consistent pseudonyms while keeping the original file format, then
> re-scans the output and releases only files that pass. No external API, no GPU. Docs are in Korean.

---

## 무엇이 다른가

개인정보를 찾아 가리는 도구는 이미 많다. deident는 그 가운데 **한국 기관이 실제로 주고받는
문서 파일**을 대상으로 아래 일을 한 번에 한다.

- **서식을 지킨 가명 사본** — `.hwpx`·`.docx`·`.pptx`·`.xlsx`를 원래 형식 그대로 고쳐 쓴다.
  표·글상자·머리말·각주·발표자 노트가 남고, AI에 넣을 마크다운이 함께 나온다.
  글자만 뽑아 가리는 방식으로는 양식 문서를 돌려줄 수 없다.
- **`●●●` 대신 `[연구자A]`** — 같은 사람·같은 기관은 어디서나 같은 가명을 받아, 가린 뒤에도
  누가 무엇을 맡는지 읽힌다. 원값↔가명 매핑은 격리 폴더에만 남고 `restore`로 되돌린다.
- **표가 알려 준 이름을 문서 전체에서 지운다** — 참여연구원 표의 `성명`·`소속` 칸에서 값을
  건져 대장에 올린 뒤, 본문·각주·도형 이름에 흩어진 같은 값을 찾는다. 자간을 벌린 표기
  (`홍 길 동`)와 앞뒤에 글자가 붙은 자리(`발표자홍길동`)까지 훑는다. 대형 NER 모델이나 GPU 없이 돈다.
- **화면에 안 보이는 자리까지 고친다** — 시트 이름, 숫자로 저장된 주민등록번호, 셀 메모,
  책갈피, 도형 대체 텍스트, 차트에 딸린 엑셀, 스마트아트, PDF 주석·책갈피·첨부 파일.
  이런 자리 48곳을 자리 하나당 합성 문서 하나로 만들어 매번 시험한다.
- **통과한 것만 `out/`에 있다** — 치환을 마친 파일을 다시 열어 같은 탐지기로 재검사하고,
  매핑에 오른 원값이 파일 안 어디에든(글자·속성값·압축 안의 압축까지) 남았는지 찾는다.
  하나라도 걸리면 그 실행의 산출물 전부를 격리한다. `out/`에 파일이 있다는 사실이 곧 통과 기록이다.
- **개인정보 밖의 것도 가린다** — 소속 기관, 과제번호, 예산, 직접 지정한 기밀어.
  연구계획서를 내보낼 때 걸리는 것은 주민등록번호만이 아니다.
- **AI는 원문을 보지 않는다** — 탐지와 치환은 전부 로컬 파이썬이고, 화면에 찍히는 요약은
  `홍*동` 식으로 가려진다. 코딩 에이전트에 실행을 맡겨도 원문이 대화로 들어가지 않는다.
- **못 본 것을 없다고 하지 않는다** — 열지 못한 파일과 미지원 형식은 '탐지 없음'으로 넘기지
  않고 '확인 필요'로 보고한다(종료 코드 3).

## 왜 이렇게 만들었나

문서를 AI에 넣기 전에 개인정보를 지우려는데, **지우는 과정에서 AI가 원문을 읽으면**
아무 의미가 없다. 그래서 탐지·치환을 전부 로컬 파이썬 코드에 두고, AI(또는 사람)가
보는 것은 `홍*동` 식으로 가려진 요약만 되게 했다.

안전을 규율이 아니라 **구조**로 보장하는 네 가지 불변식:

1. **LLM 원문 격리** — 탐지·치환은 100% 로컬. 요약에는 마스킹된 값만 실린다.
2. **out/ 불변식** — 검증 게이트를 통과한 파일만 `out/`에 존재한다. 하나라도
   불합격이면 그 실행의 산출물 전부를 격리한다. 부분 통과는 없다.
3. **매핑 격리** — 원값↔가명 매핑과 원문 대조 리포트는 `_private/`(권한 700)에만.
4. **stdout 위생** — 트레이스백에 원문 조각이 섞이지 않게, 전문은 로그 파일로만.

## 설치

파이썬 3.11 이상. 표준 라이브러리 + 아래 선택 의존성.

```bash
git clone https://github.com/parkjui92/deident.git
cd deident
pip install lxml pyyaml            # 필수
pip install kiwipiepy              # 한국어 인명 탐지 (권장)
pip install pymupdf openpyxl olefile  # PDF·엑셀·구형 한글
```

없는 라이브러리에 딸린 기능만 조용히 빠지고 나머지는 그대로 돈다.

```bash
mkdir -p work/in && cp config.example/* work/config/   # 작업 폴더 준비
python3 run.py --root work guard "work/in/문서.hwpx"
```

## 사용

```bash
python3 run.py guard "문서.hwpx"    # ① 열기 전 점검 (읽기 전용)
python3 run.py scan  "문서.hwpx"    # ② 무엇이 얼마나 잡히나 (파일 변경 없음)
python3 run.py apply "문서.hwpx"    # ③ 비식별본 생성 + 검증 게이트
```

작업 폴더는 `--root` 또는 환경변수 `DEIDENT_ROOT`, 없으면 현재 폴더.

| 명령 | 하는 일 | 종료 코드 |
|---|---|---|
| `guard` | 위험도만 빠르게 판정 | 0 없음·참고 / 3 주의 이상 **또는 검사 불가** |
| `scan` | 탐지 + 리포트 | 0 |
| `apply` | 탐지 → 치환 → 위생 → 게이트 → 리포트 | 0 통과 / 2 게이트 불합격 |
| `verify` | 산출물만 재검증 | 0 / 2 |
| `restore` | 가명 → 원값 (`_private/restored/`에만) | 0 |
| `selftest` | 합성 문서로 탐지 재현율 확인 | 0 통과 / 2 놓침 |

옵션: `--strict-only`(확실 등급만) · `--mask`(●●●, 복원 불가) · `--quick`(guard 빠른 검사)

### 폴더

```
in/         원문
out/        ★ 게이트를 통과한 산출물만 여기 온다
_private/   원값이 있는 유일한 구역 (700)
  mapping.json · *.report_full.html · failed/ · restored/ · logs/
config/     allowlist.txt · denylist.txt · settings.yaml · confidential_rules.yaml
```

## 어떻게 찾는가

| 계층 | 방법 | 잡는 것 |
|---|---|---|
| **L1** | 정규식 + 검증식 | 주민등록번호·외국인등록번호·여권·면허·전화·이메일·카드·계좌·사업자/법인번호·차량·주소·생년월일 |
| **L2** | 문서 구조 (주력) | 표 머리글(`성명`·`소속`·`생년월일`)이 지목한 칸의 값을 건져 대장에 올리고 문서 전체로 전파 |
| **L3** | 형태소 + 접미사 | 표 밖의 이름(kiwipiepy), 기관 접미사(`~연구원`·`~대학교`) |
| 사전 | 사용자 지정 | `denylist`(강제 탐지)·`allowlist`(예외)·`confidential_rules`(과제번호·예산·기밀어) |

**이름은 L2가 주력이다.** 형태소 분석기는 사전에 없는 이름을 쪼갠다(`박서준` → 박/서/준).
표에서 확실하게 건진 이름을 사전에 등록한 뒤 전파하는 편이 훨씬 정확하다.

**체크섬은 탈락 근거가 아니다.** 2020년 10월 이후 발급된 주민등록번호는 뒷자리가
무작위여서 옛 검증식을 통과하지 않는다. 검증식으로 걸러 내면 최신 번호를 통째로 놓친다.

**마무리 훑기.** 한 번 민감하다고 판정한 값은 문맥이 없는 자리에서도 지운다 —
자간을 벌려 쓴 표기(`한 국 화 학`), 앞뒤에 글자가 붙은 자리(`발표자홍길동`),
줄바꿈이 끼어든 이름, 도형 이름·대체 텍스트 같은 XML 속성까지. 전부 실문서에서
실제로 남았던 자리다.

**숨은 자리.** 본문과 표만 읽으면 문서의 절반만 본 것이다. 글자는 XML 속성(시트 이름·
책갈피·도구 설명·링크 주소)과 곁가지 파일(메모·차트·스마트아트·문서 속성), 문서 안에
통째로 든 다른 문서(차트 데이터 엑셀)에도 산다. 이 자리들을 추출 단계에서 함께 올려
탐지·치환·게이트가 같은 것을 보게 한다. 치환기만 따로 훑으면 점검 결과는 '없음'인데
파일에는 남는다. 숨은 자리에서 잡힌 것은 리포트에 그 자리 이름(`xl/comments/…`,
`page1/annot`)으로 나오고, AI 입력용 마크다운에는 싣지 않는다.

이름이 곧 참조인 자리(시트 이름·정의된 이름·책갈피)에는 대괄호를 뗀 가명을 쓴다
(`[연구자A]` → `연구자A`). 엑셀에서 대괄호는 외부 통합 문서 표기라 파일이 깨진다.
그 이름을 부르는 수식·필드도 같은 형태로 바꿔 참조가 끊기지 않는다.

## 포맷

| 형식 | 서식 보존 | 비고 |
|---|---|---|
| `.hwpx` | ○ | 표·글상자·머리말·각주·바탕쪽 + 책갈피·누름틀·양식 목록·그림 설명·문서 정보. 조판 캐시·미리보기(PrvText)·문서이력(DocHistory)·첨부 파일명·작성자 메타 소거 |
| `.docx` | ○ | 머리말·꼬리말·각주·글상자(Choice/Fallback 양쪽) + 책갈피·대체 텍스트·문서 변수·콘텐츠 컨트롤·링크 주소·차트·customXml·문서 속성. 메모·people.xml 제거. **변경 추적이 켜져 있으면 거부** |
| `.pptx` | ○ | 슬라이드·**발표자 노트** + 도형 이름·메모·차트·스마트아트·구역 이름·링크 주소·문서 속성 |
| `.xlsx` | ○ | 공유 문자열을 직접 고쳐 수식·서식·차트 보존. **숫자 셀**(주민등록번호·전화번호를 숫자로 넣은 칸)·수식과 그 저장된 결과·셀 메모·시트 이름·정의된 이름·인쇄 머리글·목록 상자·링크·도형·피벗 캐시·문서 속성 |
| `.csv` `.md` `.txt` `.html` `.json` | ○ | 줄 모양 유지 |
| `.pdf` | 레댁션만 | 검은 칸으로 덮는다(비증분 저장으로 구버전 객체까지 회수). 가명본은 함께 나오는 `.md` 사용. 민감정보가 든 주석·양식 필드·링크는 지우고, 책갈피 제목은 가명으로 바꾸고, 첨부 파일은 모두 뗀다 |
| `.hwp` (구형) | ✕ | 텍스트 추출 → 마크다운만. 서식 사본은 한글에서 `.hwpx`로 저장 후 재실행 |

워드·발표자료에 든 **포함 문서**(차트 데이터 엑셀 등 `…/embeddings/*.xlsx·docx·pptx`)는
풀어서 같은 대장으로 함께 고친다. 본문의 이름과 차트 데이터의 이름이 같은 가명을 받는다.
OLE 개체(`.bin`)처럼 열 수 없는 것은 경고로 알린다.

## 무엇을 보증하고, 무엇을 보증하지 못하는가

게이트가 보증하는 것은 **둘뿐이다**.

1. 탐지된 값은 산출물에서 제거됐다 (같은 조이너·같은 탐지기로 재검사)
2. 매핑에 오른 원값은 산출물 어디에도 없다 (zip 전 멤버의 글자와 **속성값**,
   압축 안의 압축, PDF 주석·양식·책갈피·링크·첨부·객체 사전, 원시 바이트, NFC/NFD,
   숫자 흐름까지 훑는다)

보증하지 **못하는** 것:

- **애초에 탐지가 놓친 값** — 규칙 기반 탐지기의 재실행은 같은 것을 다시 놓친다.
  차트 범례에 직함도 머리글도 없이 이름만 적힌 경우가 그렇다
- **이미지 속 글자** — 도장·서명·조직도 캡처·스캔 PDF
- **열 수 없는 포함 개체** — OLE(`.bin`), 암호가 걸린 포함 문서
- **문맥 재식별** — "국내 유일 ○○ 보유 대학"은 이름 없이도 특정된다 (경고만 표시)
- **표 구조가 남기는 정보** — 행 수가 곧 인원 수

그래서 마지막 확인은 사람이 한다. `out/*.report.html`(마스킹)로 전체를 보고,
값 대조가 필요하면 `_private/*.report_full.html`(원문 포함)을 연다.

**검사하지 못한 것을 "없음"이라 말하지 않는다.** 미지원 형식·열기 실패는
'확인 필요'로 따로 표기한다 — 이 도구가 저지를 수 있는 가장 나쁜 거짓말은 거짓 안심이다.

## 개발

```bash
python3 -m pytest tests/ -q
python3 run.py selftest
python3 tests/surfaces.py          # 숨은 자리 표 (형식 × 자리)
```

테스트에 실제 개인정보를 쓰지 않는다. `tests/synth.py`가 형태만 유효한 허구 값
(검증식만 만족하는 주민등록번호 등)을 만든다.

`tests/surfaces.py`는 숨은 자리 하나당 합성 문서 하나를 만들어 돌리고, 결과를
**깨끗함 / 게이트 차단 / 조용히 남음**으로 가른다. 판정은 도구의 게이트가 아니라 따로 짠
판정기가 한다 — 같은 코드로 채점하면 게이트가 못 보는 자리는 영영 통과로 나온다.
0.1.0에서 같은 표를 돌리면 48곳 가운데 깨끗함 10, 게이트 차단 18, 조용히 남음 20이었다.
새 자리를 다룰 때는 `CASES`에 한 줄을 더하고 이 표가 전부 깨끗해질 때까지 고친다.

구조: `extract/`(포맷별 추출, 숨은 자리는 `hidden.py`·`embedded.py`) → `detect/`(L1·L2·L3) → `entity/`(대장·가명) →
`apply/`(치환·마무리 훑기·위생) → `verify/`(재스캔·전수 탐색·게이트) → `report/`.
공용 규약은 `model.py`, 공용 치환 엔진은 `apply/xml_apply.py`.

한 문장이 여러 노드로 쪼개져 저장되는 것이 한글·워드의 기본값이라
(`<t>홍길</t><t>동</t>`), 탐지는 이어 붙인 문자열에서 하고 치환은 그 오프셋을
다시 노드 위치로 되돌린다. 탭·줄바꿈은 넘을 수 없는 경계로 심어 둔다.
